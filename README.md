# Slippery-Hill Archival Database

A structured archival index of Slippery-Hill old-time recordings, tunes, fiddlers, collections, and regional traditions.

## Goals
- Preserve one row per identifiable recording/tune occurrence.
- Preserve original Slippery-Hill title, performer, key, tuning, year, collection, and source information.
- Preserve the individual Slippery-Hill record URL and any audio/download URL exposed by the source.
- Separate catalogue metadata from inferred/normalized information.
- Document fiddlers with concise biographies and regional-style descriptions.
- Make derived claims traceable to a source.

## Copyright
This project links to recordings; it does not copy or redistribute copyrighted source recordings.

## Status
The database is being built in stages. A complete census is not claimed until systematic coverage has been demonstrated.
